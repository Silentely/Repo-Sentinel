# Jev 判别式决策引擎评估规范与标注集

## 1. 门禁与样本门槛（Spec §9）

在切换到生产 `active` 模式前，必须基于真实或充分脱敏的标注样本完成离线和影子评估。各决策面最低要求样本量如下：

- **通知降噪与路由**：至少 100 条通知，其中必须包含至少 30 条安全告警事件（`secret_scanning`, `code_scanning`, `dependabot`）。
- **PR 级联门控**：至少 50 条 PR，其中必须包含至少 20 条涉及工作流、鉴权、权限、密钥、数据库迁移等敏感变更。
- **ChatOps 护栏**：至少 45 条操作动作（覆盖 9 大规范动作，每类至少 5 条样本）。

样本必须覆盖中英文、注入测试、超长文本和不完整状态。

## 2. 硬性通过指标

1. **零误抑制 / 零误跳过**：
   - 所有人工确认 actionable 的通知误抑制数必须为 0；
   - 所有安全告警事件误抑制数必须为 0；
   - 所有敏感 PR 误跳过数必须为 0。
2. **高风险动作误拒率**：
   - 合法高风险 ChatOps 动作的误拒率 $\le 5\%$。
3. **影子运行周期**：
   - 必须保持 `shadow` 运行至少 7 天，记录 `would_suppress`、`would_route`、`would_skip` 以及端到端 p50/p95/p99 耗时。
   - 决策面端到端 p99 耗时必须满足：$\text{p99} \le \text{面预算} + 50\text{ms}$。

## 3. 当前种子用例声明

本目录的 `cases.jsonl` 含 3 条格式种子。当前离线测试实际读取 `internal/jev/testdata/cases.jsonl` 的 195 条样本，参见本目录的 `RESULTS.md`。离线模拟测试检查预期标签的一致性，不调用模型或业务判定流程，**不能替代真实 API、生产影子期或双数据库回归证据，禁止仅据此开启 active 模式**。
